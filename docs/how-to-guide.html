Your transaction assistant — how to use it

You work in Cowork. You talk to it in plain language; it reads the contract, does the date math, and sets up Follow Up Boss. You approve every date and every send. Here's the whole thing.

AOpening or updating a file

The main job. Drop the contract or point it at the Dropbox folder, and it does the rest — with you confirming.

  1. A new file comes in. You say create a new deal (or, to change one already in Follow Up Boss, update the deal for [address]). If the contract's in Dropbox, say review the contracts in my Dropbox [folder].
  2. It finds the file — a new deal, or the existing Follow Up Boss deal at that address. It never makes a duplicate; an existing file gets updated, not re-created.
  3. It reads the contract from Dropbox (or the one you dropped in) and pulls the dates — acceptance, contingency removals (CR1/CR2), close of escrow.
  4. It shows you a dates table with confidence and its source (which page it read each from). Derived dates (CR1/CR2, walkthrough) are computed the same way every time — 7 / 14 / 14 days, weekends and holidays rolled forward.
  5. Any date missing or unclear? It asks you. If it can't read one and you don't have it, that field stays blank — it will not push a guessed date to Follow Up Boss.
  6. Wrong date? Just tell it — "no, CR1 is October 4." It updates the table (and re-checks the others), then shows you the revised set.
  7. It asks: push these to Follow Up Boss? Nothing is written until you say yes.
  8. On yes, it writes the deal (dates in their fields), tags the file, and builds the task list — each task with its real due date.
⚑
Then what? The file is now live in Follow Up Boss with real deadlines. From there: the board refreshes to show it, the inbox watch starts catching its documents as they arrive, the daily sweep starts listing what's due or missing, and you can ask it to draft any email for the file. It rides the 30-day escrow clock to closing — where you send it to Cindy, then Caroline signs off.

BFixing the files already in Follow Up Boss

EThe rules it always follows

It never guesses a date. Unclear or missing → it asks or leaves it blank. A wrong contingency date is the one thing this exists to prevent.

It confirms before writing to Follow Up Boss — every time.

Emails are drafts. Anything to escrow, a lender, the other side, or a client is written for you to review and send — it never sends on its own.

Caroline signs off. At closing the file goes to Cindy to check, then to Caroline — the assistant never records a broker approval.
